OKX 6.190.0 hidden-origin → stored RPC UXSS chain

Lab-only demonstration. Delete custom network 0x72 before each run. Open this page top-level over HTTPS in the OKX DApp browser. The Add Network requester title/origin is intentionally blank. Approve Connect, Add Network, and Switch only. Reject the final TX dialog.

One click performs Connect, RPC probe, Add Network, Switch, and top-level navigation to https://httpbin.org/. The stored RPC payload then executes at that destination, waits until the native EVM bridge exists, arms the confirmed pagehide path, and navigates once more. During that page transition it requests one zero-value transaction back to the connected address, with no calldata. Rejecting the native dialog prevents broadcast.
